# 机器人地图编辑平台

当前阶段聚焦可行走区域编辑与通过性验证，定位和导航保留后续扩展。

## 功能

- 导入人工灰度栅格地图（深色像素表示障碍），原图以 BLOB 单独保存，修订不覆盖原图。
- 在真实米制坐标中绘制禁行区、调整地图原点；前端显示比例只影响 SVG 像素，不参与计算。
- 输入机器人完整宽、长尺寸，以及起点/终点朝向（度）；后端把旋转矩形整机外廓按 5° 离散。
- 在 SE(2) 配置空间进行 BFS：平移检查格间扫掠外廓，转向检查相邻朝向上的中间姿态，因此拐角、门框、贴边和反向通过都按连续过程验证，而不是只摆几个姿态。
- 修订支持前端撤回/重做、服务端保存和命名版本恢复。
- 每次验证结果连同当时的状态写入 SQLite 检查历史；地图修订和机器人尺寸修改都产生独立记录，旧结论保留其算法版本，不被覆盖。
- 工程、栅格和状态持久化在 SQLite；所有计算使用米制坐标，重开同一 URL 或改变前端显示比例后结论一致。

## 启动

```bash
cd backend
python -m pip install -r requirements.txt
./run.sh
```

```bash
cd frontend
npm install
npm run dev
```

打开 Vite 输出的地址，可使用“宽窄门示例”或“连续转向示例”。连续转向示例的直段允许 0.6×0.8 m 机器人直行和反向通过，但紧拐角会在连续 90° 转向时被整机扫掠外廓挡住；可对照较宽机器人尺寸或地图修订后的独立检查记录。

## 测试
