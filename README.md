# 机器人地图编辑平台

当前阶段聚焦可行走区域编辑与通过性验证，定位和导航保留后续扩展。

## 功能

- 导入人工灰度栅格地图（深色像素表示障碍），原图以 BLOB 单独保存，修订不覆盖原图。
- 在真实米制坐标中绘制禁行区、调整地图原点；前端显示比例只影响 SVG 像素，不参与计算。
- 输入机器人完整宽、长尺寸，后端按水平和竖直两种矩形整机外廓做保守膨胀。
- 按层中心朝向的精确矩形外廓 + 单方向扫掠膨胀生成配置空间，旋转用保守扫掠层校验；恰好贴合的门可以通行，位置到达不再等同于姿态到达。
- 起点终点同位但朝向不同时会真正检查原地转向扫掠，无法转动时给出明确原因。
- 带时间窗口的顺序检查点：要求朝向、最早/最晚时间；允许在普通区域等待，禁止停留通道内不能停车等待。
- 修改时间窗口后可保留几何路线重判，或对比调整等待位置的方案；各方案保存时间安排与地图版本。
- 失败原因区分：朝向不满足、窗口错过、道路受阻、搜索尚未完成、禁止停留区无法等待。
- 修订支持前端撤回/重做、服务端保存和命名版本恢复。
- 验证结果带算法版本；工程、栅格和状态持久化在 SQLite，重开同一 URL 后复核结果一致。

## 启动

```bash
cd backend
python -m pip install -r requirements.txt
./run.sh
```

```bash
cd frontend
npm install
npm run dev
```

打开 Vite 输出的地址，点击“使用宽窄门示例”可直接验证。示例包含宽门、窄门和贴边障碍，窄门场景下即使中心线为空，较大机器人也应判定不可通过。

## 测试

```bash
cd backend && python -m pytest
cd frontend && npm run build
```
